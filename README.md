<p align="center"><b>LMS, membership and ecommerce extras for the Switchyard CRM plugin.</b></p>

Switchyard CRM Pro is free while it's in early access.

## What it adds

- LearnDash, LifterLMS, MemberPress and Paid Memberships Pro integrations
- Full order records with line items for CRMs that model ecommerce natively
- Abandoned cart capture, taken when the email is typed at checkout
- Event tracking onto the CRM's activity timeline, for CRMs that support it
- Video engagement tags, tagging of stale accounts and tag-based redirects after login
- One CRM contact per person across a multisite network

## Requirements

- WordPress 6.4 or later
- PHP 8.1 or later
- The [Switchyard CRM](https://wordpress.org/plugins/switchyard-crm/) plugin, installed and active

## Install

Download `switchyard-crm-pro.zip` from the latest release and upload it under Plugins > Add New > Upload Plugin. Later versions show up on the WordPress updates screen.
